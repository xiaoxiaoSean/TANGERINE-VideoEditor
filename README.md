# TANGERINE-VideoEditor

TANGERINE 是面向 Windows 的简体中文桌面视频编辑器。工程文件使用 `.tvep` 保存非破坏性编辑指令，源媒体始终保持原样。应用提供素材箱、多个序列、多轨时间轴、源与节目监视器、文字和图形、效果与调色、音频处理、字幕及本地导出队列。

## 环境与启动

需要 Windows 和 .NET 10 SDK。项目引用 `FFmpeg.Static`，编码与帧处理使用随构建输出附带的本地 FFmpeg。预览系统媒体控件可用的格式还取决于 Windows 解码器。

```powershell
dotnet build TANGERINE-VideoEditor.slnx
dotnet run --project TANGERINE-VideoEditor/TANGERINE-VideoEditor.csproj
```

## 基本操作

按 **Ctrl+I** 导入媒体，或把文件和目录拖入媒体区；可在素材箱管理标签、元数据、代理与离线重链接。双击素材打开源监视器，设定入出点后插入目标轨道。将素材拖到时间轴可选择轨道及落点，也可用插入、覆盖、剃刀、波纹、滚动、滑移和滑动编辑。预览器可直接拖动文字或媒体的变换控制点；时间轴橡皮筋与属性面板共同编辑关键帧。按 **Ctrl+S** 保存项目，按 **Ctrl+E** 打开本地导出队列。

下拉菜单统一使用深色背景和浅色文字，包括可输入的字号选择框。工作区比例可以拖动分隔条修改，并在“视图”菜单保存布局。复杂合成帧由本地 FFmpeg 处理。
