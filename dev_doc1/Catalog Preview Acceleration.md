# Catalog Preview Acceleration

## 实现范围

素材库的文字、特效、滤镜和转场示例统一优先使用经过实际试编码的 GPU H.264 编码器。示例仍为 960×540、30 fps、5 秒，文字排版和转场算法使用项目预览、导出的原有实现。

GPU 加速当前覆盖视频编码。`geq` 等逐像素滤镜仍由 CPU 计算，因此另外减少非转场区间的重复计算，并缓存完成的视频。

## 编码配置

`PreviewEncodingProfile.SelectAsync` 按 NVENC、QSV、AMF 顺序选择实际可用的编码器，使用与示例相同的编码参数各试编码 3 帧 MP4。三个探测并行，每个最多等待 5 秒；同一个 FFmpeg 二进制身份共享探测任务。取消一个示例不会取消其他示例可复用的探测。

| 编码器 | 示例参数 |
| --- | --- |
| NVIDIA NVENC | `h264_nvenc`, `preset=fast`, `rc=constqp`, `qp=27`, `bf=0` |
| Intel QSV | `h264_qsv`, `preset=veryfast`, `global_quality=27`, `look_ahead=0`, `async_depth=1` |
| AMD AMF | `h264_amf`, `quality=speed`, `rc=cqp`, `qp_i/qp_p/qp_b=27`, `bf=0` |
| 软件回退 | `libx264`, `preset=ultrafast`, `tune=zerolatency`, `crf=23` |

预览专用配置通过 `TimelineExporter.ExportMp4Async` 的可选 `previewEncoding` 参数传递。没有该参数的正式导出继续使用原有编码配置。硬件编码失败会用同一滤镜图重试一次软件编码；只有重试成功才将该硬件会话标记为不可用，避免把滤镜错误误判成 GPU 故障。用户取消时不重试。

## 视频缓存与取消

缓存目录为 `%LOCALAPPDATA%/TangerineVideoEditor/catalog-previews`。缓存键包含渲染模块 MVID、样图版本、实际 FFmpeg 路径/大小/修改时间、类别/预设 ID；文字还包含完整样式和实际内容。更换渲染代码、编码器或样式后不会命中旧画面。

只有成功渲染且未取消的视频才通过临时文件和原子重命名写入缓存。每次播放复制为独立临时文件，窗口可以删除自己的播放文件而不影响缓存或其他播放。最多保留 128 个完整缓存视频、256 MiB，优先清理最久未访问的项目，同时清理一天前的崩溃遗留 `.partial` 文件。

单个渲染门控制复杂任务：旧任务取消并释放编码器后，最新任务才运行，避免快速切换积累 CPU 计算和 GPU 会话。缓存命中不启动 FFmpeg。过期的窗口请求不接受回调，并清理未交给播放器的临时文件。

## 转场计算

`TransitionRenderPlan` 根据片段本地时间只在 In/Out 活动区间启用 `geq`、`gblur`、`blend`。其他区间直接传递原图。数值时钟的静态预览使用相同表达式。

缓动进度、旋转三角函数、缩放比例、抖动偏移和模糊混合权重只在每帧的首个像素计算，其他像素复用 AVExpr 寄存器。每个表达式、色彩平面和切片线程保存各自的初始化标记及帧时钟，避免跨帧读取旧值。优化后与仅做区间旁路的版本比较，36 个转场 × In/Out 共 72 组完整 RGBA 输出哈希全部相同。

对 36 个转场、In/Out 共 72 组完整 RGBA 输出进行优化前后比较：70 组逐字节一致；模糊溶解的非活动区间最多相差 1/255，因为旧 `sin(PI)` 浮点残差造成取整偏差，旁路恢复到原始清晰画面。转场活动区间保持一致。

## 验证

`tests/CatalogPreviewCheck` 支持读取旧 DLL 进行基线测试；优化测试使用真实服务，检查视频尺寸、帧率、时长、完整解码、缓存字节一致、独立播放副本、取消和快速切换。`--cold` 只删除对应测试项的缓存以测量首次生成耗时。

`tests/PreviewEncodingCheck` 通过实际 Intel Arc QSV 编码、共享探测、卡死驱动模拟、取消和导出回退检查。硬件列表中存在某个编码器不代表该机器可用，测试必须成功编码视频。

开发机器（Intel Arc、FFmpeg 4.4）相同画幅与帧率的最终实测如下。结果不包含播放器加载时间，冷启动 GPU 探测另外耗时约 2 秒。

| 示例 | 优化前首次生成 | 优化后首次生成 | 缓存返回 |
| --- | --- | --- | --- |
| 旋转开场 | 29.656 秒 | 7.412 秒 | 2.3 毫秒 |
| 模糊溶解 | 38.930 秒 | 7.858 秒 | 2.1 毫秒 |
| 轻微抖动 | 未单独测量 | 5.819 秒 | 2.8 毫秒 |
| 数字计数 | 3.207 秒 | 3.971 秒 | 2.1 毫秒 |

GPU 初始化有固定开销，首次生成简单标题不保证比软件编码快；缓存消除后续重复生成。硬件、驱动及系统负载会影响这些耗时。原始与最终报告分别位于 `tests/CatalogPreviewCheck/artifacts/baseline.json`、`optimized-final.json`，属于本机生成的忽略文件。
