# Clip Property Clipboard

## 操作入口

“编辑”菜单提供“复制片段属性”和“粘贴片段属性到选中项”。先选择源片段并复制，再在时间轴中选中一个或多个目标片段执行粘贴。锁定轨道上的片段不会被修改；若没有目标或尚未复制，状态栏显示 `PROP-PASTE-TARGET` 或 `PROP-PASTE-EMPTY`。

## 属性范围

剪贴板只保存外观与处理参数，不替换目标媒体 ID、源入点、时间轴位置、时长或速度。视频和图形目标可以接收变换、透明度、混合模式、蒙版、效果、转场及相应关键帧；标题目标还可接收来源标题的文字样式。音频或含音频的视频目标可以接收音量、音量关键帧和基本声音设置。超过目标时长的关键帧会被忽略，避免产生工程范围之外的节点。

属性快照与目标逐项深拷贝，防止多个片段共享可变效果对象。一次批量粘贴仅生成一个撤销步骤，然后刷新时间轴与节目预览。序列化或音频参数错误使用 `PROP-COPY` 或 `PROP-PASTE` 阶段代码提示用户。
