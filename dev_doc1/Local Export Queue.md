# Local Export Queue

## 功能

文件菜单的“导出视频”和 `Ctrl+E` 打开本地导出队列。用户可以选择项目内任一序列，选择序列原始画幅、横屏 1080p、竖屏 1080p、方屏 1080p 或横屏 720p 预设，也可以直接输入偶数画幅、帧率和视频码率。码率留空时使用编码器的质量模式。当前参数可以保存为本机自定义预设，存放在用户本地应用数据目录。导出范围可选择整个序列或指定起止秒数；指定范围初始使用序列工作区间。

每个队列任务独立保存序列、输出路径和编码参数。用户可加入多个任务并移除选中任务，再按顺序批量导出。任务可使用不同序列和平台画幅。导出进度窗口显示当前任务号与编码百分比，并允许取消。队列开始时复制工程；随后每个任务再复制一次并展开嵌套序列，因此导出期间的编辑不会改变正在编码的文件。标题在专用 STA 工作线程栅格化。

## 本地编码

`TimelineExporter` 先按序列原始画幅合成所有可见视频轨和可听音轨，再裁取选定的序列时间范围，缩放到目标画幅，按目标帧率输出 H.264/AAC MP4。音频与画面使用相同的起止时间和归零时间戳。指定码率时使用目标码率、峰值和缓冲区；留空时使用 CRF 20。每个任务先编码到同目录临时 MP4，成功后才覆盖目标文件。导出目标不能与项目中的源文件或代理文件重合。

## 异常阶段

界面参数使用 `ExportDialogStageCode.Validate`，本地预设读写分别使用 `PresetRead` 和 `PresetWrite`。编码沿用 `ExportStageCode` 的 `Validate`、`Prepare`、`EncoderMissing`、`Encode` 和 `Finalize`。所有界面错误显示简体中文说明和阶段代码。

## 限制

队列在当前应用会话中运行，关闭应用后不会继续执行。视频编码依赖随 Windows 应用打包的本地 FFmpeg。旧文档中有关固定导出参数的描述以本文件为准。

## 时间重映射与交换文件

带速度节点的片段在导出滤镜图中分成多个区间。视频段分别裁取源范围、调整时间戳，再连接成一条片段流；音频段同样裁取并用 `atempo` 调速后连接。倒放段按其源范围反向读取。视频帧模式包括采样、帧混合和 FFmpeg 本地运动补帧。音乐重定时淡入淡出也加入音频导出链。

文件菜单提供“导出项目交换文件”和“导入项目交换文件”。XML 包含可读的素材、序列、轨道、片段及速度节点，同时保留完整的原生工程数据，便于在本应用往返时保存文字、效果、关键帧、遮罩等信息。CMX3600 EDL 仅用于直切视频素材的基础剪辑点交换；包含变速或倒放的视频序列会提示改用 XML。导入的相对素材路径按交换文件所在目录解析。交换失败以 `EXCHANGE-Validate/Read/Parse/Write` 阶段代码显示。
