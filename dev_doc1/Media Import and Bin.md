# Media Import and Bin

## 导入与引用

媒体面板接受从资源管理器拖入的文件或目录；工具栏、文件菜单、**Ctrl+I** 和直接拖到时间轴共用导入器。重复路径复用已有媒体 ID。拖到时间轴会同时把媒体登记到工程，片段仍只保存源媒体 ID、源入点和时间范围，不复制或改写源文件。

可导入常见视频、音频和图片格式，包括 MPEG 传输流、WebM、Ogg、TIFF、JPEG 变体、AAC、WMA 和 AIFF。导入选择器有全部媒体及按种类筛选。Windows 预览可否解码取决于本机媒体解码器；即便预览不支持，工程中的引用也会保留，用户可以重新链接或通过本地 FFmpeg 导出。

## 后台扫描与元数据

文件及目录枚举在后台执行，信号量串行化重叠导入请求；如果用户期间切换工程，旧请求不再提交到新工程。界面按小批量接收路径并刷新媒体列表。独立的 `ffprobe` 任务读取时长、画面尺寸、帧率、音视频编码、音轨、声道和采样率等可用属性，探测失败不删除素材。对暂未探测出时长的时间轴片段，程序先使用临时时长；元数据返回后，仅对尚未被用户修剪或移动的临时片段更新时长与其批次后续落点。

工程在素材箱中管理名称、标签、说明、颜色和可检索元数据。素材箱可嵌套，搜索匹配媒体名称、路径、标签及元数据。媒体路径在保存时可转为相对工程路径；离线状态会显示在列表，并可通过重新链接恢复。

## 时间轴落点与错误

拖放到时间轴时按媒体类型选择兼容、未锁定的目标轨道，并按吸附和落点确定片段位置。已有源监视器入出点会成为新片段的源范围。扫描与读取错误通过简体中文消息和 `MED-IMPORT-SCAN` 等阶段代码呈现，元数据后台返回时还会核对工程身份，避免污染已切换的工程。
