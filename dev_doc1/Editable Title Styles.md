# Editable Title Styles

## 目标与参考

基于本项目现有文字渲染器实现独立的文字排版与运动；没有复制外部软件的资源包，也不将几个不同的名字映射到同一个动画。外部软件参考链接与功能说明见 [Title and Transition References.md](Title%20and%20Transition%20References.md)。

新增五种样式：

| ID | 具体行为 | 可编辑的专用参数 |
| --- | --- | --- |
| `title.clean-lower-third` | 左下角人物信息底板从侧面减速滑入，保留画面安全边距 | 滑入时间、距离、方向、延迟、缓动 |
| `title.box-reveal` | 圆角底板与文字一起淡入淡出 | 淡入时间、淡出时间 |
| `title.outline-pop` | 粗描边大字从小比例弹出并回弹 | 弹跳时间、起始比例、回弹幅度、延迟、缓动 |
| `title.crawl` | 一整行文字横向持续滚动，从一侧经过原位再离开 | 完整路程、滚动时长、方向、延迟、缓动 |
| `title.zoom` | 文字持续从起始比例变化到结束比例，可推进或拉远 | 起始比例、结束比例、缩放时长、延迟、缓动 |

`title.kinetic` 同时执行滑入与弹跳，不再只复用弹跳动画；两组参数都开放。

## 可编辑字段

通用文字设置继续提供内容、字体、字号、粗体、斜体、下划线、文字颜色、字距、行距、描边颜色/粗细、阴影颜色/模糊/偏移/透明度及光晕参数。新增背景左右/上下内边距、圆角、背景不透明度、水平与垂直安全边距。

像素参数保存在序列坐标中，安全边距保存在 0 到 0.5 的画面比例中。界面使用百分比显示边距与运动比例。缓动支持匀速、加速进入、减速到位、平滑起止四种曲线。项目 JSON 以可空的 `TitleMotion` 参数兼容旧项目。

## 预览与导出一致性

`TitleLayout.TextOrigin` 统一文字对齐与安全边距；`TitleLayout.Background` 统一背景内边距、圆角及透明度。时间线监视器与 `TitleBitmapRenderer` 都调用它们。文字背景不再依赖 `TextBlock.Background`，避免有字距时与无字距时的背景范围不同。

`DynamicTitlePreset` 同时生成监视器数值与 FFmpeg 表达式；水平偏移、垂直偏移、缩放曲线、延迟、缓动和淡入淡出使用相同参数。导出继续使用真实透明 PNG 叠加，因此字体、描边与背景由同一 WPF 文字引擎生成。

`TitleBitmapRenderer` 的行高与监视器保持一致；监视器描边副本也使用相同行高，修复多行标题描边与填充错位。字幕草稿编辑器保留新增背景参数及原有光晕参数，防止重新保存时静默丢失。

## 验证

在独立输出目录构建通过，0 警告、0 错误。独立 STA 命令验证器执行 24 项检查：滚动起点/中点/终点与反向、缩放三时点、组合动画平移与缩放、安全边距、底板淡入淡出透明度、背景尺寸/圆角、六种透明 PNG 生成。人工检查人物信息条与圆角底板静态输出。

真实 MP4 渲染与素材库示例的一致性由主渲染回归继续验证。此处的静态 PNG 验证不宣称已完成全部交互体验验收。
