# Preview Media Transform

## 交互与数据

图片和视频片段的运动属性保存在 `ClipTransform`。选中片段后，用户可在节目监视器拖动画面调整位置，拖动角点调整水平与垂直缩放，拖动上方控制点旋转；进入“裁切”模式可分别拖动四边。位置使用序列像素，原点是画幅中心。裁切保存为源画面比例。锚点 X/Y 在属性窗口中以裁切后可见画面的 0–100% 表示，默认 50%/50%；它作为缩放和旋转枢轴，绿色十字显示其实际位置，PositionX/Y 控制锚点相对序列中心的偏移。缩放、旋转和位置按片段属性及关键帧插值求值。

拖动开始后仅在确实更改属性时保存一次撤销快照。锁定轨道仍可观看，不能修改。`ClipAnimation` 在播放头处求属性值，时间轴修剪或分割时会相应裁切、平移片段关键帧。节目监视器的控制点以播放头处实际缩放和旋转画出；进入裁切模式后还可拖动绿色锚点，拖动锚点会补偿位置以保持当前画面。拖动已有关键帧的媒体时，整条位置、缩放或旋转曲线平移，避免下一帧跳回旧值。预览变换与导出共用这些工程属性。

## 多层预览

普通单层素材可由 WPF 视觉对象显示；叠放、视觉效果、蒙版、混合或转场需要合成时，`CompositeFrameRenderer` 按当前播放头从本地媒体解码并生成合成帧。播放过程中限制请求频率，定位与暂停会请求准确帧。合成帧已经包含媒体的空间变换，显示时不再对整幅结果重复施加单片段变换。选中叠放的底层图片或视频后，监视器仍显示该片段的控制点；拖动时异步刷新合成帧，不移动整张合成位图。文字覆盖层继续按序列画幅绘制。导出使用同一工程属性和本地 FFmpeg 处理链。

切换到新的效果片段时，渲染请求会先更新当前源身份并立即发起首帧任务；在异步结果返回前隐藏原始媒体，以免未经处理的画面闪现。渲染失败时显示占位信息与阶段代码，后续播放头移动可重新请求画面。

预览分辨率可设为全、二分之一或四分之一；该选择仅影响监视器的处理量，不改变序列规格或导出质量。源文件不会因预览而修改。解码失败会显示带阶段代码的错误消息。
