# Text Styling

## 编辑入口与数据

从“文字”类别添加标题片段后，可直接在节目预览器中拖动标题改变位置，双击标题或预览器中未命中媒体控制点的画面区域打开样式窗口并选中内容；同一时刻有多条标题时，优先编辑已选标题，否则编辑画面顶层标题。时间轴片段双击、右键“编辑文字”及属性按钮也会打开同一窗口。样式包含安装字体、字号、粗体、斜体、下划线、前景与背景色、横纵向对齐、描边、阴影、行高、字距和精确位置。输入的数值与颜色会先校验，确认后才写入工程。

标题数据存储在 `ClipText`，未知 JSON 字段通过 `JsonExtensionData` 保留。编辑标题会记录撤销快照并将工程标记为未保存。位置、缩放、旋转和透明度可通过关键帧动画；播放头变化时标题重新排版并求值。属性窗口显示播放头处的位置；对已有位置关键帧的标题改动位置时，平移整条曲线并保留各关键帧的相对运动。对齐选择以中文显示，工程仍保存稳定的英文枚举值，兼容旧工程。

## 预览与导出

预览器按序列画幅计算标题布局，再叠放在节目画面上。选中标题会显示边框；拖动手势将位置更新为序列像素并合并为一个撤销步骤。已有位置关键帧时，拖动会平移整条位置动画路径，使松开鼠标后的预览不会跳回旧关键帧位置。图形和文字同属一个标题片段，拖动其中任一可视对象都会同步移动另一对象。字距不为零时，`LetterSpacingText` 以文字簇为单位排版，保持换行、对齐和组合字符的间隔一致。

导出时 `TitleBitmapRenderer` 在序列分辨率下把标题栅格化为透明图片，再由 FFmpeg 与可见视频轨合成。预览和导出共用字距测量与绘制逻辑。字体具体外观取决于本机安装字体；工程仅保存字体族名称，不复制字体文件。文字内容和样式编辑均不会修改源媒体。
