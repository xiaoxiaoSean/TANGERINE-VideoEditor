# 工程预缓存

打开工程后立即调度视频和音频预缓存。普通选择、滚轮浏览、播放与音乐试听不会取消工程预缓存；真实数据修改、工程切换、画质或预览尺寸变动才撤销旧请求。修改以 250 毫秒去抖重新规划，不会在未提交的拖动中间拍摄工程快照。

视频按约 3 秒且对齐序列帧的区间渲染，优先当前播放头及其后方的缺失区间，每完成一段即原子发布供预览使用；无需等待整个工程完成。全部区间完成后以流复制拼接，作为减少段边界重新打开播放器的优化，拼接失败不会撤销已完成区间。播放时保留实时音频监控和静音、独奏控制。

区间缓存键使用实际视觉字段、源文件时间戳和大小、效果外部文件依赖、画布及预览分辨率。名称、分组、轨道锁定、空轨道、媒体分类与纯音频参数不会无故重建视频。重新规划复用未变的内容键，仅渲染失效区间。缓存目录为 exe 同级的 `cache/timeline-v4`。

缓存前以稳定 occurrence 标识展开嵌套序列；同一子序列被多次放置仍有不同稳定标识。展开时保留轨道扩展数据，避免丢失轨道音效。视频分段只加载区间涉及的可见素材及跨边界转场必要的相邻素材，保留片段原始时间、源偏移、动画曲线与动态文字时钟，不通过缩短或平移对象伪造局部时间。视频预缓存不探测、混合或编码音频。

后台结果受工程引用、工程代次、内容版本和请求版本保护。旧任务取消后先等待编码进程退出及后台任务完成，之后才能释放旧工程解包媒体。临时文件不作为有效缓存，取消或失败不会发布半成品。

静态检查及 Debug 构建不代表已实际验证播放性能、GPU 编码驱动或全部转场画面。当前区间输出保留原始合成时钟；持续时间很长的单个片段仍可能需要从其原始动画时钟处理到目标区间，这是避免重置动态效果的兼容性取舍。
