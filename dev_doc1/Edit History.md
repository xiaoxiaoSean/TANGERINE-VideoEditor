# Edit History

## 历史窗口

“编辑 → 编辑历史”显示最近的工程快照、当前工程以及可重做的快照。列表按时间先后显示，用户选择记录并点击“转到所选记录”即可连续执行相应次数的撤销或重做。窗口最多列出最近 30 次已保存的撤销快照；历史不会写入 `.tvep` 工程文件。

历史基于既有的 JSON 工程快照，恢复时会取消旧项目的后台元数据请求，重新建立界面选择、时间轴与预览。恢复期间禁用编辑，以免后台反序列化与当前操作并发。正在导入、导出、拖动或执行其他历史恢复时拒绝跳转，并以 `HIST-NAVIGATE-BUSY` 等阶段代码说明状态。历史恢复失败沿用 `HIST-RESTORE` 错误处理。

恢复前会把已展开的 `.tvep` 内嵌媒体缓存租约转给新工程对象，避免撤销/重做后关闭项目时留下缓存，或后续预览失去有效路径。互换快照的 JSON 工作放在后台；替换工程及刷新界面仍在 WPF 界面线程完成。
