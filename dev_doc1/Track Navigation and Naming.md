# 轨道命名与视图滚动

## 轨道重命名

在轨道名称区域右键，选择「重命名轨道…」。轨道空白区域的右键菜单以及顶部「轨道」菜单也提供入口。

名称会去掉首尾空白，须为 1–128 个字符，不允许换行及其他控制字符。名称相同则不产生撤销记录。重命名即时刷新轨道，写入项目文件，并支持撤销、重做；锁定轨道仍允许修改显示名称。对话框打开期间若项目或轨道已被替换，拒绝修改过期对象。校验错误使用 `TMLNE0015`。

## 轨道视图导航

| 输入 | 行为 |
| --- | --- |
| 普通纵向滚轮 | 上下滚动轨道区域 |
| 鼠标原生横向滚轮 | 左右滚动时间轴 |
| Shift＋纵向滚轮 | 左右滚动时间轴 |
| Ctrl＋纵向滚轮 | 非 MCP 接管期间缩放时间轴 |

WPF 不直接提供横向滚轮事件，因此窗口通过 `HwndSource` 处理 `WM_MOUSEHWHEEL`。仅在指针位于轨道滚动区域内时消费消息；保留有符号的屏幕坐标，并转换为 WPF 坐标以支持副屏和高 DPI。窗口关闭时移除消息钩子。

MCP 接管期间允许轨道视图纵向、横向滚动及 Shift＋滚轮浏览；不允许 Ctrl＋滚轮缩放。浏览只改变视图偏移，不改动项目、撤销记录或 MCP 的最后活动时间。其他区域滚轮、鼠标编辑、键盘编辑、命令和关闭窗口继续受控制模式限制。为接收真实滚轮消息，接管期间窗口不再整体禁用原生输入，而由 WPF 类输入守卫和关闭守卫拦截编辑。

## 验证

`tests/TrackRenameCheck`：18 项实际 WPF 窗口检查，包括名称对话框、即时刷新、撤销、保存与重新加载、普通滚轮、原生左右滚轮、Shift 导航及 MCP 浏览例外。

`tests/McpControlCheck`：46 项控制模式检查，包含实际申请控制权后发送纵向路由事件及原生横向滚轮消息，验证视图发生滚动、项目版本和空闲计时不变，同时保留其他输入拦截、超时释放和后台任务保护。
