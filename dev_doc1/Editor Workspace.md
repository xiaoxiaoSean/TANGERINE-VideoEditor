# Editor Workspace

## 目标与界面

TANGERINE 使用简体中文的 Windows WPF 工作区。主窗口包含菜单、快捷操作栏、素材／对象区、预览器、时间轴和状态栏。上下区域及素材／预览列采用比例网格，用户可拖动分隔条调整布局。`App.xaml` 对所有下拉框和下拉项设置深色背景、浅色文字，并对悬停和选中状态提供独立对比度；字号等可编辑下拉框的输入框同样使用浅色文字。

“视图 → 工作区”提供剪辑、调色和音频布局，可以保存当前布局并恢复。布局、预览分辨率、时间轴缩放、自动保存开关和自定义快捷键保存在本机用户配置目录的 `workspace.json`，与工程素材引用分开。文件读写失败显示 `WORKSPACE-SAVE` 或 `WORKSPACE-RESTORE` 阶段代码。

## 时间轴操作

时间轴支持多轨拖放、选择和 Ctrl 多选、轨道排序、锁定、隐藏、静音及同步锁定。片段可移动、复制、剪切、粘贴、插入、覆盖、分割、拖边修剪、波纹修剪和波纹删除；滚动、滑移及滑动编辑在片段右键菜单。吸附可切换，播放头可拖动定位。每次工程编辑保存撤销快照；撤销和重做恢复项目模型及界面选择。

“时间重映射”对视频或音频片段设置片段相对时间的速度节点。节点之后的区间使用该节点的速度，`ClipTimeMap` 统一计算预览、冻结帧和导出的源时间。视频可选择帧采样、帧混合或光流插值。分割、修剪和覆盖操作会平移或裁减节点，避免源时间跳变。滚动和滑动编辑仅处理常速邻段，以免改动已有变速曲线。

## 预览与效果

原始视频由 WPF 媒体控件播放。需要效果处理时，本地 FFmpeg 解码帧，预览控件显示效果、蒙版和调色后的图像。播放期间限制效果帧请求频率，暂停与逐帧定位仍使用精确播放头位置。预览区保留位置、缩放、旋转和裁切的拖动控制点。源素材和工程文件都不会因预览发生修改。

## 项目与错误

工程使用 `.tvep` 版本化 JSON。素材路径可相对工程文件保存；失联文件可重新链接。用户可在项目面板管理素材箱、元数据、标签、序列、嵌套序列、标记和代理。保存与读取经 `ProjectFileService` 包装阶段代码。编辑器的输入校验和本地导出错误也会显示对应阶段代码。
