# Project Media and Sequences

## 功能范围

项目保持 `.tvep` 非破坏性结构：导入媒体和代理的字节保存在单文件容器中，片段只保存媒体 ID、源时间范围和编辑参数，不改写源媒体。当前打开的序列继续使用清单根节点的 `Sequence`、`Tracks`、`Markers` 字段，其他序列保存在 `Sequences` 中，旧工程没有新字段时仍可读取。

## 素材箱与检索

媒体面板增加素材箱筛选和管理入口，可创建嵌套素材箱、重命名、删除、移动素材。删除素材箱只改变工程内归属，子素材箱与素材移到上一级，源文件不变。搜索覆盖素材名称、标签、说明、路径和探测到的媒体元数据。素材元数据包括时长、分辨率、帧率、音视频编码、声道、采样率、文件大小、修改时间和容器／摄像机标签。媒体行显示离线和代理状态。

选中媒体后可编辑显示名称、标签颜色、标签词及说明。右键“查看媒体元数据”可核对来源。媒体导入支持文件、多文件和目录拖入；重复路径复用原媒体 ID。`ffprobe` 后台收集技术元数据，不阻塞导入完成。

## 源监视器与入出点

双击媒体打开源监视器。窗口位于素材区上方，节目监视器保持可见，便于并列比较。视频／音频可播放、暂停与拖动进度，图像静态显示。按钮可在当前源时间设置入点、出点、源标记，或将所选源区间插入时间轴目标轨道。源时间范围也可在媒体右键菜单中输入秒数。以后从媒体面板添加到时间轴的片段会继承源入点与可用时长；已添加的片段保留自己的源范围，不受后续媒体默认值修改影响。

## 多序列与嵌套

序列选择框切换当前时间轴。可用横屏、竖屏、方形及 4K 预设创建序列，或根据所选媒体的分辨率和帧率创建序列；还可复制、重命名、修改规格、删除序列。被其他序列嵌套引用的序列须先移除引用才能删除，避免留下无法保存的工程。由媒体创建序列时，已知源入出点必须包含可用时长，不会自动延长到媒体结尾之外。切换保留各序列的轨道和标记。序列标记可输入名称与备注，管理界面可定位、编辑和删除。

“将其他序列嵌入时间轴”在当前视频轨创建序列片段。编辑状态保留在内层序列；片段右键可打开内层。添加时拒绝循环引用。导出前 `SequenceFlattener` 递归展开内层引用，在同一输出时间基准上组合媒体片段，并检查缺失序列与循环；标题图片在展开之后渲染，使嵌套文字也进入最终视频。

## 代理、重链接与整合

可附加现有代理或用本地 FFmpeg 生成较轻的 MP4 代理，切换预览时使用代理路径，原始媒体路径保留用于高质量导出。代理先写到同目录的临时文件，成功后再替换目标文件。项目保存时，源媒体和代理均嵌入 `.tvep` 容器；打开时提取到会话缓存。

播放和拖动预览游标时，代理有效路径从内存状态读取，文件存在性在后台定期刷新；代理离线后自动回退原始媒体。用户主动附加、生成、重链接或切换代理时立即更新内存状态，因此这些操作不用等待下次后台刷新。

素材列表中的“离线”和“代理”状态也来自后台文件检查快照。刷新列表、搜索和滚动时不直接访问磁盘；状态在路径改变后刷新，并在用户再次查看素材区时按时间间隔更新。

单个媒体可选择同类型新文件重链接；批量重链接会扫描选定文件夹，通过文件名、类型及可用的文件大小匹配离线媒体。附加代理和单文件重链接的容量预检按替换后的路径计算，不再把失效的旧路径当作必需文件；异步检查结束前若工程或素材已变化，会放弃过时操作。重链接后若还有其他离线文件，修改保留在当前编辑会话并显示未保存状态，待全部重链接后才能把所有媒体完整嵌入工程。整合命令写入独立的 `.tvep` 工程副本，其中包含当前工程的媒体和代理，原工程与原素材不变。离线媒体会阻止整合，并返回明确的阶段代码。

## 错误阶段与兼容性

用户可见错误均附阶段代码，如 `MED-SOURCE-RANGE`、`MED-PROXY-CREATE`、`MED-RELINK-MATCH`、`MED-CONSOLIDATE` 和 `SEQ-NEST-CYCLE`。工程文件验证检查素材箱父级循环、序列 ID 重复、嵌套引用、片段时间以及源入出点。新增字段均有默认值，旧 `.tvep` 文件仍可打开。WPF 的源监视器预览依赖系统可用解码器；导出和代理生成依赖随程序提供或 PATH 中的 FFmpeg。
