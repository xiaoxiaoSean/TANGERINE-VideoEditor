# 图像序列导入

## 入口与数据流

“文件 → 导入图像序列…”选择连续编号图片的第一帧，例如 `shot_0001.png`。扫描在工作线程上完成，从所选编号开始查找同目录、相同前缀、相同数字位数和扩展名的连续文件；检测到后续编号但中间缺号时给出校验错误。少于两帧或编号超出范围时拒绝导入。

本地 FFmpeg 以当前序列帧率把图片编码为 H.264 MP4，随后复用普通媒体导入流程：检查 `.tvep` 所在卷空间、将生成的视频登记到媒体区，并嵌入项目容器。时间线按视频片段处理，源图片仍保持原样。编码和项目保存异步执行，错误在状态栏显示 `MED-SEQUENCE-*` 阶段代码。

## 边界

图像序列以首帧为起点，不能跨缺号。编码前异步检查临时盘空间；常规媒体导入阶段再检查项目目标盘空间。导入失败时清理未被项目引用的临时视频。导入后项目携带生成的视频，不依赖原图片文件；编辑原图片不会自动更新已经导入的序列。此流程不改变既有 `.tvep` 模型或版本。
