# 本地多机位剪辑

## 创建

按住 Ctrl 在时间轴选择至少两个不同视频源的片段，打开“剪辑 → 从所选视频创建多机位…”或片段右键菜单中的同名命令。可选择按照当前时间轴位置、源时间码或本地音频波形同步。时间码读取素材导入时保存的 `timecode` 元数据；音频波形调用本地 FFmpeg 解码和相关性分析。同步过程不使用网络或云服务。

系统取所有机位共同有画面的区间，建立共享零点和时长。原机位片段由一个多机位切段代替，可通过撤销恢复。组内每个角度保留原视频源、入点、画面属性和关键帧。创建要求正向原速视频，且所选轨道未锁定。

本地源文件检查在后台运行，避免网络盘或较慢磁盘使界面等待。同步完成后重新核对工程、轨道与源片段的状态；期间有编辑变动时中止本次创建。

## 切换角度

把播放头放在紫色多机位切段内，点击预览标题栏的“多机位”按钮，然后选择角度。播放中也可点击；播放头位置按帧率对齐，并写入新的切段。当前切段前半段保持原机位，后半段切换到新机位。每段存储 `MulticamLocalStartSeconds`，使角度变更后仍从共享时间基准取对应源帧。点击现有切段开头会替换该段的角度。

切换角度所需的源文件检查也在后台运行。检查期间若播放头或目标片段改变，会提示重新选择，避免在旧时间写入机位切点。

预览标题栏只显示当前最上层可见画面对应的多机位角度。若上方另有图片、视频、颜色片段或嵌套序列覆盖，标题栏不会误指向下层多机位切段。

时间轴片段使用所选角度的 `MediaAssetId` 和 `SourceInSeconds`，因此现有预览、音频监听、本地 MP4 导出按实际切段读取素材。修剪、分割、插入和覆盖会同步维护组内起点。切段保存于 `.tvep` 项目；XML 项目交换的原生负载保留多机位元数据。多机位切段被编辑为变速或反向时，角度切换会给出 `MULTICAM-EDIT` 阶段代码，避免无法对齐的源时间。

## 实现位置

- `Project/ProjectDocument.cs`：多机位组、角度和切段字段。
- `MainWindow.Multicam.cs`：同步、创建、角度选择、切段和错误提示。
- `MainWindow.Timeline.cs` 与 `MainWindow.AdvancedTimeline.cs`：入口、可视区分及剪辑边界维护。
- `MainWindow.PaperEdit.cs`：文本粗剪拆分多机位切段时同步推进其共享时间基准，粗剪轨道插在源轨道上方。
- `Project/ProjectFileService.cs`：项目保存与加载时的多机位引用校验。
