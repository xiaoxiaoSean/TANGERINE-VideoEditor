StageCode format: five uppercase ASCII letters (component) + four decimal digits (failure branch).
Codes are stable across languages. Never allocate codes from localized exception text.
ErrorDialog is the shared UI boundary. Preserve known StageException and explicit domain mappings;
only unexpected exceptions use the caller's fallback. Causes/actions are chosen by exception types,
then the component head, without changing the stage identifier. Malformed identifiers use UNKWN0001.
0001.. domain mappings below are explicit and must not change when an enum is reordered.
9999 is reserved for an unknown enum member in a known domain. 0900..0999 identify UI boundaries.
Register new codes here before use. Resources/StageList.txt ships alongside the application.
