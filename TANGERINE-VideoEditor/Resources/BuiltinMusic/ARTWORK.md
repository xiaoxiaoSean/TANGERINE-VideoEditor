# 内置音乐封面

每首曲目均配有一张根据风格制作的原创封面，文件位于 `thumbnails/`。封面以不同的乐器、山峦、合成器网格、唱片、几何图案等表现原声、氛围、电子、节奏蓝调、低保真、摇滚、游戏等风格；曲目标识作为稳定的随机种子，使同一风格内也有不同的构图。

这些图片由仓库中的 `tools/GenerateMusicArtwork.py` 在开发时离线绘制，不使用第三方照片、唱片封面或字体图片。图片已随音乐资源保存，用户打开软件时不生成封面，也不需要图像生成服务。

`artwork.json` 保存每张封面的风格、相对路径与 SHA-256，供资源维护使用。重新生成需要 Python 和 Pillow；正常使用编辑器没有这些依赖。图像不属于音乐作品自身的官方封面，音乐来源和授权应以 `manifest.json` 与 `LICENSES/` 为准。
