# 内置音乐来源与许可

100 首完整器乐来自作曲者 Rrrrrose 的官方音乐站 Loyalty Freak Music，包含其 Komiku、Loyalty Freak Music、Monplaisir 艺名。每首选中作品所在的官方专辑页均明确链接 CC0 1.0；逐专辑原页存放于 albums/。

许可：CC0 1.0 Universal，允许复制、修改、商业使用与再分发，无需取得额外许可。许可全文见 CC0-1.0.txt（如官网返回 HTML，则为 CC0-1.0.html）；作者 FAQ 原页见 Author-FAQ.html。并未依赖“免费下载”推定再分发权。

仅提取原始 ZIP 中的完整 MP3；不截取、不拼接、不改变速度、不重编码。统一移除 ID3 APIC 内嵌专辑图片，避免将第三方专辑图一起打包。sourceSha256 为原 MP3，sha256 为去图后的打包文件，audioPayloadSha256 为不含头尾 ID3 的音频数据，采集器会确认前后相同。软件缩略封面另行生成。

风格按原专辑器乐编配分类；排除明确歌曲/人声专辑、翻唱混音和来源说明含不确定采样的专辑。保留原作品名称与作者姓名，并提供自愿署名文本。作品不得被登记为自身独占的 Content ID 内容。

manifest.json 包含逐曲原始专辑页、下载 ZIP 地址、原 ZIP 文件名、作者、原始分类、时长、许可和校验值。evidence-index.json 记录采集时许可证据文件的 SHA-256。
